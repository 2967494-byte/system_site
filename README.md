# DentX System — Лендинг программного комплекса

Официальный промо-сайт специализированного программного комплекса для центров дентальной рентген-диагностики **DentX System**.

## 🚀 Стек технологий
- **HTML5** (семантическая разметка, доступность, SEO-оптимизация)
- **CSS3 / Vanilla CSS** (адаптивная вёрстка, glassmorphism, тёмная/светлая темы, scroll-driven анимации)
- **JavaScript (ES6+)** (плавная прокрутка, динамические счётчики, интерактивная галерея скриншотов Lightbox, модальные окна, маски ввода)

## 📁 Структура проекта
```
├── index.html       # Главная страница лендинга
├── privacy.html     # Политика конфиденциальности (152-ФЗ)
├── consent.html     # Согласие на обработку персональных данных (152-ФЗ)
├── style.css        # Полные стили и анимации
├── app.js           # Логика интерактивности и контроллеры
├── images/          # Скриншоты реального интерфейса и графика
└── README.md        # Описание проекта
```
